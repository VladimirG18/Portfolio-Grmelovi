API klíč pro ceny akcií (nepovinný)

Ceny i grafy se stahují bez klíče – kryptoměny z CoinGecku, akcie a ETF z Yahoo Finance. Klíč od Twelve Data je tu už jen jako záloha, kdyby Yahoo u nějakého titulu selhalo. Když ho zadáš, uloží se sdíleně (do stejné databáze jako pozice), takže ho druhý z vás nemusí zadávat znovu.

Nemusíš nic vyplňovat.

Free tarif Twelve Data nepokrývá evropské burzy (XETRA, Euronext…) – na tyhle tituly vrací „This symbol is available starting with the Grow or Venture plan“. Proto se ceny berou primárně z Yahoo Finance, kde jsou zdarma a bez limitu kreditů.

Kdybys klíč přesto chtěl (hodí se pro americké tituly jako záloha): zaregistruj se na twelvedata.com, v sekci API Keys / Dashboard zkopíruj klíč, vlož ho níže a ulož.

Vlastní proxy pro ceny akcií (nepovinné, ale spolehlivé)

Ceny akcií se berou z Yahoo Finance. Prohlížeč tam ale nesmí sáhnout přímo (pravidlo CORS) a Yahoo navíc z evropských adres často dotaz odmítne, dokud nedostane souhlas s cookies. Stránka proto zkouší veřejné přeposílací služby – ty ale bývají blokované rozšířeními v prohlížeči nebo DNS filtrem a občas přestanou fungovat.

Vlastní proxy tenhle problém odstraní natrvalo. Zdarma a za pár minut si ji postavíš na Cloudflare Workers:

  1. Přihlas se na dash.cloudflare.com → Workers & Pages → Create → Start with Hello World.
  2. Celý obsah editoru nahraď tímhle kódem a dej Deploy:
export default {
  async fetch(request) {
    const target = new URL(request.url).searchParams.get('url');
    if (!target) return new Response('chybí ?url=', { status: 400 });
    if (!/^https:\/\/query[12]\.finance\.yahoo\.com\//.test(target))
      return new Response('jen Yahoo Finance', { status: 403 });
    const r = await fetch(target, { headers: { 'User-Agent': 'Mozilla/5.0' } });
    return new Response(r.body, {
      status: r.status,
      headers: {
        'Content-Type': r.headers.get('Content-Type') || 'application/json',
        'Access-Control-Allow-Origin': '*',
        'Cache-Control': 'public, max-age=60'
      }
    });
  }
};

Worker pustí dál jen dotazy na Yahoo Finance, takže ho nikdo nemůže zneužít k něčemu jinému. Zdarma zvládne 100 000 dotazů denně, což je řádově víc, než tahle stránka potřebuje.

  1. Zkopíruj adresu workeru (např. https://neco.tvuj-ucet.workers.dev), vlož ji níže a ulož – uloží se sdíleně, takže ji stačí zadat jednou.

Heslo pro vstup na stránku

Heslo je zašité (jako hash) přímo v kódu stránky – nejde o silné zabezpečení, jen odradí náhodné návštěvníky. Změnu hesla si řekni Claude Code v repozitáři (přepočítá hash a nahradí ho v assets/gate.js).

Otisk / Face ID na tomto zařízení

Po prvním zadání hesla na daném telefonu nebo počítači se nabídne nastavení odemykání biometrií (otisk, Face ID, Windows Hello) – funguje jen na tom jednom zařízení, kde se nastaví, a je to pořád jen pohodlnější náhrada hesla, ne skutečné ověření identity.

Měna a přepočty

Hodnota a zisk se ukazují hlavně v měně dané pozice, menším písmem pod tím je přepočet do měny, kterou si vybereš v přehledu (Kč / € / $); součty nahoře jsou v ní taky, protože sčítají různé měny dohromady. Přepočítává se referenčním kurzem ECB (Frankfurter, při výpadku náhradní zdroj) platným v okamžiku zobrazení – tedy ne historickým kurzem ke dni nákupu. Je to střední kurz bez marží, takže se nebude přesně shodovat s tím, co účtuje banka nebo broker.
