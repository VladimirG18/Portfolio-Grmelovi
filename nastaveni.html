API klíč pro ceny akcií a ETF

Kryptoměny se stahují automaticky bez klíče (CoinGecko). Pro akcie a ETF je potřeba vlastní zdarma klíč od Twelve Data – ukládá se jen v tomto prohlížeči (localStorage), nikam se neposílá ani se neukládá do repozitáře.

Jak získat klíč (cca 2 minuty, zdarma):
  1. Jdi na twelvedata.com a zaregistruj se (stačí e-mail).
  2. Po přihlášení najdeš v sekci API Keys / Dashboard svůj klíč (dlouhý řetězec znaků).
  3. Zkopíruj ho a vlož do pole níže.

Zdarma tarif má limit cca 800 dotazů/den a 8/minutu – pro rodinné portfolio to bohatě stačí. Klíč si musí vložit každý zvlášť ve svém prohlížeči.

Heslo pro vstup na stránku

Heslo je zašité (jako hash) přímo v kódu stránky – nejde o silné zabezpečení, jen odradí náhodné návštěvníky. Změnu hesla si řekni Claude Code v repozitáři (přepočítá hash a nahradí ho v assets/gate.js).

Měna a přepočty

Součty v přehledu jsou vždy v korunách. Cizí měny (USD, EUR, GBP) se přepočítávají aktuálním kurzem (Frankfurter, kurz ČNB/ECB) v okamžiku zobrazení – nejde tedy o historický kurz ke dni nákupu.
